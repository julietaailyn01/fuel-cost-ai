# FuelCost AI

FuelCost AI is an end-to-end Machine Learning application that estimates
the fuel consumption of a trip based on its distance.

## ML Problem

The first version uses simple linear regression to learn the relationship
between:

- Input feature: trip distance in kilometers
- Target: fuel consumed in liters

The estimated fuel consumption is later combined with the fuel price
provided by the user to calculate the estimated trip cost.
